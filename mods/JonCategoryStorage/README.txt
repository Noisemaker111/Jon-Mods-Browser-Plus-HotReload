Jon's Category Storage (Beta)

Sort items into categories such as books, medicine, food, ammo, tools, weapons, armor, attachments, resources and building materials. Put one representative item in a chest, then use Smart / Move matching to move other items in that category. One book matches books, magazines and schematics; one attachment matches item mods. Empty chests are not catch-all destinations, and chest labels do not select categories. Fill still fills matching stacks, and All keeps its normal behavior. Item quality, attachments, stack limits and locked slots are preserved.

Installation
Close the game. Extract the ZIP and copy the JonCategoryStorage folder into %AppData%\7DaysToDie\Mods. Start the game with EAC disabled. For multiplayer, install the same version on the host and every player.

Beta
Experimental beta for 7 Days to Die V3.2.0 (b10). In-game behavior and multiplayer are unverified.

Permissions
Re-uploading or including this mod in a public mod pack requires the author's permission.
