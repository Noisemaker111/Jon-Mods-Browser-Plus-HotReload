Jon's Loot Skulls (Beta)

Marks POI buildings you have looted with a skull over the building: the share of its loot containers searched ("58% looted · 7/12 containers"), hours until loot respawns and zombies still inside. Only containers that belong to a POI count; loose nests, trash piles and player-built storage are ignored. The countdown follows the world's loot respawn settings and nearby-player delays. Respawned or reset containers drop out of the count. Markers are saved separately for each world.

Installation
Close the game. Extract the ZIP and copy the JonLootSkulls folder into %AppData%\7DaysToDie\Mods. Start the game with EAC disabled. For multiplayer, install the same version on the host and every player.

Beta
Experimental beta for 7 Days to Die V3.2.0 (b10). In-game behavior and multiplayer are unverified.

Permissions
Re-uploading or including this mod in a public mod pack requires the author's permission.
